# Ordered (ranked) flat and nested stochastic block models

Native C++ implementation of Peixoto's (2022) flat and nested ordered
(ranked) stochastic block models for directed networks, matching
graph-tool's `RankedBlockState` and
`NestedBlockState(base_state = RankedBlockState)`. Jointly infers
community assignments and an ordinal ranking of groups that explains
global directional flow (upstream, lateral, and downstream edges).

## Usage

``` r
ranked_block_state(graph, blocks = NULL, u = NULL, distance = FALSE,
  unique = FALSE, M = NULL, degree_corrected = TRUE,
  degree_prior = c("distributed", "uniform"))
ranked_description_length(state, label_dl = TRUE, degree_prior = NULL)
minimize_ranked_blockmodel_dl(graph, distance = FALSE, unique = FALSE,
  M = NULL, degree_corrected = TRUE,
  degree_prior = c("distributed", "uniform"), B_min = 1L, B_max = Inf,
  refine = TRUE, epsilon = 1e-3)
nested_ranked_block_state(graph, levels = NULL, u = NULL, distance = FALSE,
  unique = FALSE, M = NULL, degree_corrected = TRUE,
  degree_prior = c("distributed", "uniform"))
nested_ranked_level_entropy(state, degree_prior = NULL)
nested_ranked_description_length(state, degree_prior = NULL)
minimize_nested_ranked_blockmodel_dl(graph, distance = FALSE, unique = FALSE,
  M = NULL, degree_corrected = TRUE,
  degree_prior = c("distributed", "uniform"), B_min = 1L, B_max = Inf,
  refine = TRUE, epsilon = 1e-3)
ranked_vertex_order(state, normalize = FALSE)
ranked_edge_directions(state)
ranked_edge_counts(state)
compare_ordered_models(graph,
  models = c("unordered_flat", "unordered_nested",
    "ranked_flat", "ranked_nested"),
  degree_corrected = TRUE, degree_prior = c("distributed", "uniform"),
  method = c("map", "posterior"),
  evidence_method = c("variational", "importance"),
  nruns = 1L, nsamples = 200L, thin = 5L, burnin = NULL, mle = TRUE,
  B_min = 1L, B_max = Inf, refine = TRUE)
```

## Arguments

- graph:

  A directed graph created by
  [`graph_create`](https://diogro.github.io/rgraphtool/reference/graph.md)
  with `directed = TRUE`.

- blocks:

  Optional integer vector of 1-based group memberships of length
  `graph_num_vertices(graph)`. Defaults to a single group.

- levels:

  Optional list of at least two 1-based integer group membership vectors
  defining a nested hierarchy over the directed graph.

- u:

  Optional finite integer vector of length at least \\(B\\) assigning
  each level-0 group an ordinal rank. Defaults to `0:(B - 1)`.

- distance:

  If `FALSE` (the default), edge orientation probabilities depend only
  on whether \\(u_r \< u_s\\), \\(u_r = u_s\\), or \\(u_r \> u_s\\); if
  `TRUE`, edge orientation counts are stratified by rank distance
  \\(\|u_r - u_s\|\\).

- unique:

  If `FALSE` (the default), multiple groups may share the same rank
  drawn from \\(\\{0, \dots, M - 1\\}\\); if `TRUE`, all groups have
  strictly distinct ranks.

- M:

  Size of the discrete rank alphabet when `unique = FALSE`. Defaults to
  the number of vertices \\(N\\).

- degree_corrected:

  Whether to fit the degree-corrected (`TRUE`) or non-degree-corrected
  (`FALSE`) ranked SBM.

- degree_prior:

  Degree sequence hyperprior (`"distributed"` or `"uniform"`).

- state:

  A flat `rgraphtool_ranked_block_state` or nested
  `rgraphtool_nested_ranked_block_state` object.

- label_dl:

  Whether to include the rank-label prior term \\(\ln \binom{M + B -
  1}{B}\\) (when `unique = FALSE`).

- B_min, B_max:

  Minimum and maximum number of level-0 occupied groups.

- refine:

  Whether to run greedy refinement and rank-optimization sweeps after
  merge-split minimization.

- epsilon:

  Stopping tolerance in nats for greedy refinement.

- normalize:

  If `TRUE`, rescale vertex ranks to \\(\[0, 1\]\\).

- models:

  Character vector naming a subset of `"unordered_flat"`,
  `"unordered_nested"`, `"ranked_flat"`, `"ranked_nested"`,
  `"ranked_distance_flat"`, and `"ranked_distance_nested"`.

- method:

  Compare models by `"map"` minimum description length or full Bayesian
  `"posterior"` marginal evidence.

- evidence_method:

  Evidence estimator forwarded to
  [`model_evidence`](https://diogro.github.io/rgraphtool/reference/compare_model_classes.md)
  when `method = "posterior"`.

- nruns:

  Number of independent minimization restarts per model.

- nsamples, thin, burnin, mle:

  Posterior sampling and entropy estimation controls forwarded to
  [`model_evidence`](https://diogro.github.io/rgraphtool/reference/compare_model_classes.md).

## Details

In the ranked SBM, the undirected multigraph of edge counts \\(m\_{rs} =
e\_{rs} + e\_{sr}\\) is generated by an undirected SBM (or an undirected
nested hierarchy at levels \\(l \ge 1\\)), while edge orientations
between groups \\(r\\) and \\(s\\) are governed by their relative ranks
\\(u_r\\) and \\(u_s\\). When `distance = FALSE`, minimization
canonicalizes distinct group ranks into contiguous integers \\(0, \dots,
K-1\\) oriented so that upstream edges (\\(u_r \< u_s\\)) outnumber
downstream edges (\\(u_r \> u_s\\)) without altering the exact
description length.

Flat and nested ranked states integrate with
[`block_membership`](https://diogro.github.io/rgraphtool/reference/block_state.md),
[`block_sizes`](https://diogro.github.io/rgraphtool/reference/block_state.md),
[`nested_levels`](https://diogro.github.io/rgraphtool/reference/minimize_nested_blockmodel_dl.md),
[`nested_project`](https://diogro.github.io/rgraphtool/reference/minimize_nested_blockmodel_dl.md),
[`nested_summary`](https://diogro.github.io/rgraphtool/reference/minimize_nested_blockmodel_dl.md),
[`mcmc_sweep`](https://diogro.github.io/rgraphtool/reference/mcmc_sweep.md),
[`mcmc_equilibrate`](https://diogro.github.io/rgraphtool/reference/mcmc_sweep.md),
[`mcmc_anneal`](https://diogro.github.io/rgraphtool/reference/mcmc_sweep.md),
[`sample_posterior`](https://diogro.github.io/rgraphtool/reference/mcmc_sweep.md),
[`model_evidence`](https://diogro.github.io/rgraphtool/reference/compare_model_classes.md),
[`plot_ranked_hierarchy`](https://diogro.github.io/rgraphtool/reference/plot_hierarchy.md),
and
[`plot_hierarchy`](https://diogro.github.io/rgraphtool/reference/plot_hierarchy.md).

## Value

`ranked_block_state()` and `minimize_ranked_blockmodel_dl()` return a
`rgraphtool_ranked_block_state` list. `nested_ranked_block_state()` and
`minimize_nested_ranked_blockmodel_dl()` return a
`rgraphtool_nested_ranked_block_state` list.

`ranked_description_length()` and `nested_ranked_description_length()`
return total description lengths in nats;
`nested_ranked_level_entropy()` returns per-level contributions.

`ranked_vertex_order()` returns a numeric vector of per-vertex ranks.
`ranked_edge_directions()` returns an integer vector with `1L`
(upstream, \\(u_i \< u_j\\)), `0L` (lateral, \\(u_i = u_j\\)), and `-1L`
(downstream, \\(u_i \> u_j\\)) for every edge. `ranked_edge_counts()`
returns a list with counts `upstream`, `lateral`, `downstream`, and
`internal`.

`compare_ordered_models()` returns a
`rgraphtool_ordered_model_comparison` list with ranked `summary`,
`best_model`, `best_state`, `states`, optional `evidences`, and
`log_bayes_factors`.

## Examples

``` r
set.seed(1)
tier <- rep(1:3, each = 5L)
ed <- list()
for (i in 1:15) for (j in 1:15) if (i != j) {
  p <- if (tier[i] == tier[j]) 0.7 else if (tier[j] > tier[i]) 0.35 else 0.02
  if (runif(1) < p) ed[[length(ed) + 1L]] <- c(i, j)
}
g <- graph_add_edges(graph_create(15, directed = TRUE), do.call(rbind, ed))
st <- minimize_ranked_blockmodel_dl(g)
st
#> <ranked block state: degree-corrected, B = 3, 20 upstream / 43 lateral / 1 downstream, DL = 159.3705 nats>
ranked_edge_counts(st)
#> $upstream
#> [1] 20
#> 
#> $lateral
#> [1] 43
#> 
#> $downstream
#> [1] 1
#> 
#> $internal
#> [1] 43
#> 
```
